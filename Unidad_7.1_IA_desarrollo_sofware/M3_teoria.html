Marco Conceptual

El Espectro de Delegación

En ingeniería de software aumentada, el éxito no reside en cuánto código genera la IA, sino en la **fricción cognitiva** que el ingeniero decide tolerar.

Regla de Oro: Delegamos la sintaxis, pero nunca la arquitectura. La responsabilidad ética y técnica del código es 100% humana.

Módulo 01

Chat Mode

La Dimensión Dialógica del Desarrollo.

Interacción Dialógica

El Consultor Socrático

El modo Chat permite inyectar el **@contexto** necesario para que la IA comprenda no solo la línea actual, sino la intención del sistema completo.

  • Análisis Contextual: Inyección selectiva de AST y LSP.
  • Diagnóstico: "¿Por qué este algoritmo de Grafos genera un ciclo infinito?".
  • Refinamiento: Iterar sobre la lógica antes de aterrizar en el código duro.
AED III en Acción

Debugging de Árboles AVL

Caso Real: Un alumno intenta corregir un rebalanceo complejo. El Chat no escribe el código, explica la rotación.

// Prompt sugerido:
"@file:AVLTree.cpp explica por qué el factor de equilibrio no se está actualizando tras una rotación doble a la derecha."

Impacto Cognitivo

El ingeniero aprende a depurar mediante el razonamiento asistido, no mediante el "copy-paste". Es el uso de la IA como mentor 24/7.

Módulo 02

Autocomplete

Inferencia Predictiva en el Estado de Flujo.

Mecánica del Token

Fill-In-the-Middle (FIM)

El autocompletado no es predictivo de palabras; es predictivo de **bloques lógicos**. El modelo recibe el prefijo y el sufijo para predecir el centro.

PRE: void quicksort(int arr[], int l, int h) {
FIM -> [INFERENCIA DE IA]
SUF: }
Performance Crítica

La Regla de los 100ms

Para que el autocompletado sea útil, la inferencia debe ocurrir en menos de 100ms. Si hay lag, se rompe el flujo creativo.

Configuración: Usamos modelos de 1.5B parámetros (ej. Qwen 1.5B) exclusivos para esta tarea en el config.yaml.

Riesgos Cognitivos

La Competencia Fantasma

Aceptar sugerencias automáticas sin auditar genera una falsa sensación de dominio técnico.

Riesgo: Código sintácticamente correcto pero algorítmicamente ineficiente (O de n^2 cuando se requería O log n).

Lógica del Agente

El Patrón ReAct (Reasoning + Acting)

El agente no escribe código de inmediato. Sigue un bucle iterativo:

  • Pensamiento: "Necesito leer BST.h para ver la definición de la clase".
  • Acción: Ejecuta comando de lectura de archivo.
  • Observación: "Veo que falta el constructor de copia".
  • Planificación: Proponer la implementación del constructor.
Delegación Real

Automatización de SDLC

El Agente es ideal para tareas repetitivas de alta carga sintáctica pero baja carga creativa.

• Generación de Tests: "/edit crea 5 unit tests para la función de inserción en el grafo".
• Refactorización: "/edit convierte todos los punteros raw a smart pointers (std::unique_ptr)".

Módulo 04

Plan Mode

El Blueprint Estratégico antes de la Acción.

Fase de Diseño

Estrategia antes de Táctica

El modo Plan descompone requerimientos ambiguos en una estructura lógica. Es vital para evitar el "Código Espagueti".

  • Roadmaps: Pasos secuenciales de codificación.
  • Análisis de Impacto: ¿Qué archivos se romperán al cambiar esto?
  • Validación Estructural: Alineación con patrones de diseño (SOLID).
Diseño Técnico

Blueprinting de un Módulo de DB

Consulta: "@codebase necesito un sistema para persistir el Grafo de rutas en una base de datos SQLite."

Plan Generado:

  1. Crear interfaz IDataPersistence.
  2. Implementar clase SQLiteAdapter en /db.
  3. Diseñar esquema de tabla para 'Aristas' y 'Nodos'.
  4. Actualizar main.cpp para inyectar persistencia.

Ética y Profesionalismo

Soberanía del Pensamiento

La IA debe ser una palanca para elevar nuestro nivel de abstracción, no una prótesis para anular nuestra capacidad crítica.

Responsabilidad: El ingeniero es el autor legal y técnico. Si no puedes explicar una línea de código, no te pertenece.

Repaso Conceptual 01

Orquestación Contextual

Aprendimos que la IA es tan buena como el contexto (@file, @codebase) que el agente le inyecta. Sin contexto, hay alucinación.

¿Por qué Ollama?

Garantizamos soberanía de datos y latencia determinística. CAPEX sobre OPEX.

Repaso Conceptual 02

Estrategia de Modelos Duales

Inferencia de Pensamiento

Modelos >7B para Chat y Agent. Buscamos lógica arquitectónica sólida.

Inferencia de Escritura

Modelos < 3B para Autocomplete. Buscamos respuestas en milisegundos.

Repaso Conceptual 03

El Ciclo del Token

Desde la intención humana hasta la VRAM. El flujo de streaming permite ver la "pensada" del modelo antes de aceptarla.

Repaso Conceptual 04

Auditoría Humana Obligatoria

Toda sugerencia de la IA debe pasar por el filtro de la verificabilidad. Si no hay test, no hay verdad técnica.

El Ingeniero es el Orquestador: La IA es el instrumento, pero el humano es el director de la orquesta algorítmica.
